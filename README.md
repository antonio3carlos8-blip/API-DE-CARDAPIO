🍔 Cardápio Digital

O Cardápio Digital é uma aplicação web desenvolvida para facilitar a criação e o gerenciamento de cardápios de restaurantes, lanchonetes e outros estabelecimentos alimentícios.

O sistema permite cadastrar, visualizar, atualizar e excluir produtos, além de organizar os itens por categorias, como hambúrgueres, bebidas e sobremesas. Os usuários também poderão pesquisar e filtrar os produtos disponíveis no cardápio.

A aplicação será composta por um frontend, responsável pela interface do usuário, e uma API REST, responsável pelo gerenciamento dos dados e pela comunicação com o banco de dados.

A API utilizará PostgreSQL para armazenar as informações e Prisma para realizar a comunicação com o banco de dados. A API também contará com documentação de seus endpoints, facilitando sua utilização e manutenção.

Como funcionalidade adicional, o usuário poderá selecionar produtos e montar um pedido, visualizando os itens escolhidos e o valor total.

O projeto será desenvolvido utilizando tecnologias estudadas durante o curso e será disponibilizado em produção através da Vercel, integrando frontend, API e banco de dados.

Principais funcionalidades
Cadastro de categorias;
Edição e exclusão de categorias;
Cadastro de produtos;
Edição e exclusão de produtos;
Consulta e pesquisa de produtos;
Filtro de produtos por categoria;
Controle de disponibilidade dos produtos;
Montagem de um pedido;
Cálculo do valor total do pedido;
API REST documentada;
Integração com banco de dados PostgreSQL;
Deploy da aplicação em produção.
